# Checkpoint 06: encuesta ampliada

Carpeta reservada para la encuesta que incorpora recursos que Google Forms no ofrece o resuelve mal.

## Estado

Pendiente de desarrollo. No debe presentarse todavía como un estudio funcional.

## Criterio para completarlo

Deberá incluir aleatorización del orden, lógica condicional, un control de atención ficticio y registro de tiempos de respuesta, con una verificación documentada de todas las ramas y de los datos obtenidos.
