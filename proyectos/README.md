# Proyecto acumulativo y checkpoints

Esta carpeta reúne versiones recuperables de `mi-primer-estudio`. Cada checkpoint corresponderá a un momento del libro y deberá funcionar de manera independiente antes de considerarse terminado.

## Etapas previstas

1. `01-inicial`: documentación básica del proyecto.
2. `02-primer-jspsych`: primera ejecución local.
3. `03-formulario`: preguntas y validaciones.
4. `04-escalas`: escala didáctica y datos asociados.
5. `05-aleatorizacion`: orden, muestreo o condiciones aleatorias.
6. `06-encuesta-ampliada`: aleatorización, lógica condicional, controles de atención y tiempos de respuesta aplicados a la encuesta.
7. `07-estudio-completo`: integración, pilotaje y documentación.

## Estado

Los checkpoints `01-inicial` a `06-encuesta-ampliada` están completos y fueron probados con jsPsych 8.3.0. Las demás carpetas están reservadas para evitar que una estructura vacía se confunda con un estudio funcional. Cada una deberá incorporar instrucciones de ejecución y criterios de verificación cuando se desarrolle.

Los checkpoints `02` a `06` cargan jsPsych desde Internet, por lo que necesitan conexión para funcionar.
