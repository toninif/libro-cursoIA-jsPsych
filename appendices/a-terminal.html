29  Comandos de terminal

29.1 Cómo usar este apéndice

Este apéndice reúne los comandos de PowerShell, los comandos de Codex y los atajos de teclado que aparecen en el libro. Cada entrada indica para qué sirve, un ejemplo, el resultado esperado y el capítulo donde se explica en detalle.

No incluye comandos que el libro no haya usado. Si necesitás uno nuevo, consultá la documentación oficial y aplicá la regla de siempre, que es ejecutar solo instrucciones cuyo propósito puedas explicar.

Antes de ejecutar cualquier comando que modifique archivos

Comprobá la carpeta actual con Get-Location y su contenido con dir. Un comando bien escrito puede actuar sobre una carpeta equivocada.

29.2 Comandos de PowerShell

29.2.1 Ubicarse y recorrer carpetas

Resultado esperado. Get-Location muestra una ruta. dir muestra una lista con nombres, fechas y tamaños. La columna LastWriteTime indica la fecha y la hora de la última modificación de cada archivo, lo que sirve para detectar qué archivos cambió un agente (capítulo 9). Después de cd, el indicador muestra la nueva ubicación.

29.2.2 Crear y leer

Advertencias. Usá siempre -Encoding UTF8 con Get-Content. Sin ese parámetro, la versión de PowerShell incluida en Windows puede mostrar las tildes como símbolos extraños, aunque el archivo esté bien. En Select-String, el asterisco de *.js significa “todos los archivos con extensión .js”.

29.2.3 Programas y procesos

Recordá. Interrumpir no es deshacer. Ctrl + C detiene el trabajo pendiente, pero lo que ya ocurrió permanece.

29.3 Instalar y comprobar Codex

El instalador oficial de Codex para Windows se ejecuta con este comando. El capítulo 7 explica cada una de sus partes.

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Después de instalar, estos comandos permiten comprobar e iniciar Codex.

El comando de instalación ejecuta lo que descarga

Copiá el comando de instalación desde la documentación oficial de Codex y comprobá la dirección antes de presionar Enter. Nunca ejecutes un comando que combine irm e iex si no conocés su origen. El capítulo 7 explica cada parte del comando.

29.4 Comandos y teclas dentro de Codex

Los comandos que comienzan con / configuran la sesión. No se envían al modelo como pedidos. Escribí solamente / para ver la lista completa.

Los nombres de estos comandos pueden cambiar entre versiones de Codex. Si alguno no funciona, escribí / y buscá el equivalente en la lista.

29.7 Una rutina de trabajo en la terminal

Muchas actividades del libro siguen la misma secuencia. Podés usarla como recordatorio.

1. Get-Location              ¿Estoy en la carpeta correcta?
2. dir                       ¿Están los archivos que espero?
3. codex                     Iniciar el agente en esa carpeta
4. /status                   ¿Los permisos son Read Only?
5. (pedido y revisión)       Leer la propuesta antes de aprobar
6. /exit                     Cerrar el agente
7. dir                       ¿Cambiaron los archivos esperados?
8. Get-Content ... -Encoding UTF8    ¿El contenido es el pedido?
